# Zul Yatman Portfolio Website - Project Status & Handover

## Project Overview
Personal engineering portfolio for **Zul Yatman** (Senior Software Engineer / QA Automation Architect).
Target Platform: GitHub Pages (`zulyatman.github.io`).

## Design & Engineering Principles
- **No AI-generated boilerplate aesthetic**: avoid flashy neon gradients, floating cards, meaningless percentage skill bars, and generic marketing buzzwords ("passionate guru").
- **Senior Developer & Engineering Craft**: Clean typography, disciplined whitespace, dark/light mode toggle with persistence, documentation-style layout, architecture-focused case studies.
- **Tone**: High-ownership, impact-driven, highlighting 10+ years across e-commerce, core banking, streaming, and retail.

## Website Architecture
- `src/layouts/Layout.astro` - Main layout with dark/light mode, metadata, accessibility.
- `src/pages/index.astro` - Overview hero, featured case studies, engineering impact, quick contact.
- `src/pages/about.astro` - Technical narrative, philosophy, background.
- `src/pages/experience.astro` - Full career trajectory (Eiger, Bukalapak, Vidio, BBM, Aprisma, SDP).
- `src/pages/projects/` - In-depth engineering case studies.
- `src/pages/notes/` - Technical journal & engineering essays.
- `src/pages/resume.astro` - Web-optimized CV & printable resume.
